
# The Cozy Plate

The Cozy Plate is a recipe website created as part
of the Module 3 JavaScript Assignment.

## Project Overview

The website will help users explore simple recipes,
search for meals, filter recipes by category and
view cooking instructions.

## Planned Pages

- Home
- Recipes
- Single Recipe page

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Status

Currently in development.
